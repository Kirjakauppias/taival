# Taival – Project Plan

## 1. Overview

Taival is a responsive shared calendar application designed for two users. Its purpose is to simplify the coordination of work schedules, personal activities and shared plans.

## 2. Goals

- Develop a functional Flutter Web application.
- Provide a simple and intuitive calendar interface.
- Enable two users to view and manage events.
- Synchronize calendar data securely.
- Build a maintainable and testable codebase.
- Document the development process for portfolio purposes.

## 3. Event categories

| Category | Description |
|---|---|
| Work shifts | Work schedules of the first user |
| Personal events A | Personal activities of the first user |
| Personal events B | Personal activities of the second user |
| Shared events | Activities and plans involving both users |

## 4. Functional requirements

- Users can sign in securely.
- Users can view all four event categories.
- Users can create, edit and delete calendar events.
- Events include a title, date, start time, end time and optional description.
- Changes are synchronized between users.
- The interface supports mobile and desktop layouts.

## 5. Non-functional requirements

- Responsive design
- Secure authentication and authorization
- Maintainable architecture
- Automated testing
- Clear documentation
- Reliable error handling

## 6. Development strategy

Development will proceed incrementally. The first versions will use local sample data. Firebase integration will be introduced after the core calendar functionality has been implemented and tested.

## 7. Future scope

- Apple Calendar event import
- Recurring events
- Notifications and reminders
- Additional user preferences
- Progressive Web App improvements
